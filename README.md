# Repo Reel

Превратите ссылку на публичный GitHub-репозиторий в короткий вертикальный ролик: описание, звёзды, выдержки README, фрагмент кода и ритм последних коммитов. Данные загружаются из публичного API GitHub, а визуальная сцена и экспорт создаются в браузере. Аккаунт и сервер не нужны.

## Открыть приложение

[Запустить Repo Reel в браузере](https://hilsetapp.github.io/repo-reel/)

## Локальный запуск

Откройте `index.html` либо запустите локальный сервер:

```bash
python3 -m http.server 4174
```

Страница будет доступна по адресу `http://localhost:4173`. Сборка и внешние библиотеки не требуются.

## Экспорт и браузеры

- GIF кодируется локально из Canvas, без внешней библиотеки.
- MP4 предлагается только если браузер сообщает поддержку MP4/H.264 через `MediaRecorder`. Эта поддержка зависит от браузера и операционной системы; она не гарантирована. Если кнопка недоступна, экспортируйте GIF.
- Ролик рассчитан на вертикальный формат 9:16 и длится 30 секунд. У GIF ограниченная палитра; это совместимый, но более тяжёлый формат.

## Данные и ограничения

Repo Reel поддерживает публичные репозитории GitHub. Для чтения нужны запросы к `api.github.com`; GitHub ограничивает число запросов без авторизации. Приватные репозитории не поддерживаются. README может быть очень большим, лишённым описания или содержать данные, которые не удаётся красиво показать; перед экспортом проверьте предпросмотр. График основан максимум на 100 последних коммитах и не является полной историей проекта.

Ролик формируется локально. Repo Reel не загружает видео и не публикует его от вашего имени. В кадр добавляется отметка «Made with Repo Reel» и ссылка на исходный репозиторий.
